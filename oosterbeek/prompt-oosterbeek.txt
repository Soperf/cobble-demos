# Task: Generate a single-page Riverside Camping & Glamping website demo (Cobble pipeline, Live Redesign stage)

You are the Builder Agent for the Cobble project (AI-built hospitality websites for independent European retreats, B&Bs, and boutique campings). Generate a complete, production-quality single-page website redesign demo for the real property **Oosterbeeks Rijnoever** in Oosterbeek, Netherlands (https://oosterbeeksrijnoever.nl/). Write the file `index.html` in the directory `oosterbeek/`. This is a live cold-outreach pitch demo, so visual polish, editorial warmth, and emotional resonance are paramount.

  - 60 Riverside grass pitches under weeping willows, plus water's edge hiker spots for long-distance trails (Maarten van Rossumpad, Rosandapad Klompenpad).

    1. **De Pipowagen**: Romantic wooden gypsy wagon with veranda, double bed + bunk, full kitchenette, floodplain vistas.

- Tone of voice: Serene, warm, authentic Dutch hospitality. Understated editorial luxury (Kinfolk / Kip Hideaways standard). Multilingual support with an instant in-page toggle between Dutch (NL) and English (EN).

## Design System

- Dutch Riverside Editorial: Earthy, luminous, serene, calm water tones.
- Fonts: Playfair Display (editorial serif headings) + Lato (clean modern body), loaded via Google Fonts CDN with `font-display: swap`.
- Palette:
  - Background: Warm Chalk / Linen Linen `#FBF9F5`, Warm Card `#F4EFEA`
  - Primary Accent: Rhine Deep Forest Green `#1F382B`
  - Secondary Accent: Willow Sage `#405C4B` / `#5C7C68`
  - Warm Highlight: Campfire Terracotta & Dutch Clay `#C27A45` / `#D4A373`
  - Border & Dividers: Muted Warm Sand `#E5DFD5`
  - Text: Deep Charcoal `#1E2621`, Secondary Muted `#55635A`
  - Contrast meets WCAG 2.1 AA throughout.
- Imagery: Authentic high-resolution photographs downloaded directly from the property into `images/` (aerial drone view, willow lane, river pitches, pipowagen, retro caravan, boat on land, koffie haven terrace, apple pie, river swimming, and campfire sunset).
- Micro-interactions: Subtle card elevations, smooth anchor scrolling, IntersectionObserver reveal-on-scroll (respecting `prefers-reduced-motion`). ZERO wobbling, fake wave canvas, or synthetic distortion effects.

## Technical Constraints

- Single self-contained `index.html` file (with relative `images/` references). All CSS and JS inline.
- Mobile-first responsive: Tested flawlessly at 375px and 1440px. No horizontal scrollbars.
- Native date pickers (`<input type="date">`) with check-in today min and check-out check-in + 1 min.
- Anti-spam honeypot field.
- Interactive room preference synchronization: clicking "Reserveer / Enquire" on any accommodation card automatically selects that option in the booking form.
- Full Schema.org `Campground` & `LodgingBusiness` JSON-LD metadata.
